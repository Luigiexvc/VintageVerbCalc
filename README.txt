VINTAGEVERB — PERSONAL WEB APP

Included files:
index.html, manifest.webmanifest, sw.js, icon.svg, icon-192.png, icon-512.png, apple-touch-icon.png

PUBLISH FREE WITH GITHUB PAGES:
1. Create a GitHub account at github.com if you don't have one.
2. Create a NEW PUBLIC repository, for example: vintageverb-app.
3. Upload ALL files from this folder to the root (top level) of the repository, then commit.
4. In the repository go to Settings > Pages > Build and deployment.
5. Set Source: Deploy from a branch; Branch: main; Folder: /(root). Save.
6. After deployment, visit https://YOUR-USERNAME.github.io/vintageverb-app/
7. On iPhone Safari, open this URL, tap Share > Add to Home Screen, and turn on Open as Web App if offered.

The app works offline after its first successful visit while online. All settings are calculated on your device. No account or backend is needed for app use.

NOTE: This version is a tempo-reactive settings calculator, not an audio effect. Predelay = 20% of a beat and decay = 3.71 * 97 / BPM, following the previous conversation's creative preset. Fixed controls intentionally remain fixed.
